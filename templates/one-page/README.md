# TACEDGE one-page collateral template v1.0

Status: provisional (D10) · Owner: Mike Coom · Updated: 2026-07-15
Fonts: Play, Be Vietnam Pro, JetBrains Mono (install from Google Fonts; not distributed). Office fallbacks: Arial / Consolas.
Regenerate outputs with the scripts in /scripts — never edit exported PDFs or previews by hand.

## Files
- `TACEDGE_One_Page_Template_v1.0.html` — blank editable master (A4).
- `TACEDGE_One_Page_Example_v1.0.html` — generic worked example.
- Matching PDFs + `previews/`.

## Rules
- Word counts are printed in each placeholder; respect them.
- QR code: minimum 22×22 mm with a 3 mm quiet zone.
- Export: open in a browser, print to PDF at A4 / 100% / backgrounds on
  (or run `node scripts/export-one-page.mjs`).
- No customer details in the master. The Hunter Civil leave-behind is archived prior artwork.
