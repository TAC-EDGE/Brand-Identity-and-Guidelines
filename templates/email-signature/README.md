# TACEDGE email signature v1.0

Status: provisional (D10) · Owner: Mike Coom · Updated: 2026-07-15

## Files
- `TACEDGE_Email_Signature_v1.0.html` — HTML signature (light backgrounds, inline styles).
- `TACEDGE_Email_Signature_v1.0.txt` — plain-text version.

## Rules
- Name (bold), role, phone, email, website, location. Nothing else.
- The compact brandmark tile is optional and loads from the hosted brand site; delete that cell for a text-only signature.
- No banners, quotes, social icons (no approved TACEDGE social accounts) or image-heavy layouts.
- Signature fonts are the recipient's system fonts by design (Arial stack); brand fonts are not required.

## Installation
- **Outlook (web/desktop):** Settings → Compose → Signatures → paste the rendered HTML (open the file in a browser, select all, copy).
- **Apple Mail:** Settings → Signatures → paste; untick "Always match my default message font".
- **Gmail:** Settings → General → Signature → paste.
Replace every [bracketed] field before saving. Check the result on a phone.
